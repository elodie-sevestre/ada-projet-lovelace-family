# Vue d'ensemble du projet

**Lovelace Family** est une application de gestion de tâches entre membres d'une famille, fun et gamifiée pour donner envie de participer. Elle s'adresse aux parents et à leurs enfants.

## Fonctionnalités principales (V1)

- 🔐 Connexion
- ➕ Création de tâche
- 👤 Assignation de tâche
- 👁️ Visualisation des tâches
- ✅ Validation des tâches
- ✏️ Modification des tâches

## Stack technique

- **Frontend** : React + Vite
- **Backend** : Node.js / Express
- **Base de données** : PostgreSQL
- **Orchestration** : Docker Compose
